# About the Game

Dungeon is an exploration based game where, you move around the medivel castle to look for the treasure. But, the exploration are not easy, it is filled with traps and obstacles. Watch out for them.

## Key Movements
1. Arrow Keys = Movement
2. Space key = Action (punch or shoot)

## Traps
1. Ghosts = they follow a specific path gurading their area. 
2. Spiders = they randomly roam here, and there on the game but if you come close to it, it will start to chase you.
3. Scorpion = if the cage of scorpion gets broken, it copies your movement with double the speed
4. Push traps = if these are triggered, you will get shot from hidden bows
5. Shooter = A radar that looks for you and if you are in its shooting zone, you will get hit by sword.

## Mini Games
1. Four level sokoban where, user should solve the game to unlock the treasure
2. Watch out, you are left in arena where random side will fire arrows, your target is to stay in shielded region to be protected from them
3. Clear the maze, you can use your gun to clear the maze and get to the treasure
